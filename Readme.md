# 🏙️ Kanpur Bhraman – MVP Document (v1.0)

A tourism-focused web application aimed at helping visitors explore Kanpur with ease.

---

## 📌 1. Core MVP Features

- **Landing Page (`/`)**: 
  - Hero section with city branding
  - Live info: current weather, date, etc.
- **History Page (`/history`)**: 
  - Lists Kanpur’s cultural, historical, and heritage information
  - Fetches and displays multiple history sections
- **Attractions Page (`/attractions`)**: 
  - Browse all major places to visit with images, descriptions, timings, entry fees, and tags
  - Search bar for keyword search and category-based filtering
  - Expand/collapse attractions list
- **Place Details (`/place/:id`)**: 
  - Detailed info for each place (description, images, timings, map link, etc.)
  - Displays all reviews for the place
  - Submit new reviews (name, email, rating, comment)
- **Trip Planner (`/trip-planner`)**: 
  - Generate an auto-planned trip based on selected places and preferences
  - Shows planned route and estimated visit time
- **Contact Page (`/contact`)**: 
  - Contact form for user inquiries
- **Navigation & Layout**: 
  - Responsive navigation bar and footer on all pages

**Additional Features:**
- Integrated Google Maps links for places
- “See More”/“See Less” functionality for attractions
- Review system with live updates after submission
- Error and loading handling for all data fetches

## 🧩 2. Database Schema

### `places` Collection
| Field           | Type               | Description                                                    |
|-----------------|--------------------|----------------------------------------------------------------|
| _id             | ObjectId (PK)      | Unique ID (auto-generated by MongoDB)                          |
| name            | String             | Name of the place (required)                                   |
| description     | String             | Details about the place                                        |
| images          | Array[String]      | Multiple image URLs                                            |
| category        | Array[String]      | Place type(s): Religious, Parks, Historical, etc.              |
| address         | String             | Location/address                                              |
| map_link        | String             | Google Maps Link                                              |
| location        | GeoJSON Point      | { type: 'Point', coordinates: [longitude, latitude] }          |
| opening_hours   | String             | Visiting hours                                                |
| entry_fee       | String             | Ticket price info                                             |
| tags            | Array[String]      | Descriptive tags                                              |
| estimated_time  | Number             | Estimated visit time in minutes (default: 60)                  |
| average_rating  | Number             | Average rating (0-5)                                          |
| review_count    | Number             | Number of reviews (default: 0)                                 |
| createdAt       | Date               | Auto-generated creation date                                   |

### `reviews` Collection
| Field      | Type           | Description                                |
|----------- |----------------|--------------------------------------------|
| _id        | ObjectId (PK)  | Unique ID (auto-generated by MongoDB)      |
| place_id   | ObjectId (FK)  | Reference to `places` collection           |
| name       | String         | Reviewer name (required)                   |
| email      | String         | Reviewer email (required)                  |
| rating     | Number         | Star rating (1-5, required)                |
| comment    | String         | Review text                                |
| createdAt  | Date           | Auto-generated review submission date       |

## 📊 3. Data Collection Strategy

- Used **Google Maps**, **Wikipedia**, and **UP Tourism portals** to extract place details.
- Required fields:
  - Name, Description, Address
  - Timings, Entry Fee, Tags
  - Map link and images
- Use **Unsplash** / **Imgur** for royalty-free or custom image hosting.
- Populate demo reviews to test the review feature.
- Use **OpenWeatherMap API** for weather data on the landing page.
